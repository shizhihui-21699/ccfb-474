# 三维地层建模工具 (geo3d-modeler)

浏览器端三维地质建模:WebGL2 + TypeScript,数据全在本地,无需服务器。

## 运行

```bash
npm install
npm run dev        # 开发模式
npm run build      # 产出 dist/
npm run preview    # 预览构建产物
npm run smoke      # 核心算法冒烟测试 (node, 不需要浏览器)
```

## 功能

- **钻孔管理**:孔口 / 测斜 / 分层三张表的查看、编辑、增删行;三表一致性校验
  (引用不存在的孔、超孔深、层段重叠、岩性不在地层表等),问题行标红并给出提示。
- **测斜换算**:最小曲率法 (minimum curvature) 把测斜(测深/顶角/方位角)换算为
  真实三维孔迹,岩芯柱按岩性分段上色、沿真实孔迹摆放。
- **三维建模**:层厚度法 —— 地表(DEM)与各层真厚度分别用**普通克里金**或
  **反距离加权 (IDW)** 插值成网格,自上而下累加得到各层顶底界面;厚度夹紧 ≥ 0,
  为 0 处即**尖灭**,机制上杜绝界面交叉。
- **断层**:正断层把模型分成两盘分别插值,下降盘界面整体减去断距,断层线处
  界面断开、生成断层崖壁;网格剖分对断层线做精确裁剪 (Sutherland–Hodgman)。
- **封闭地质体**:每层每盘由顶面 + 底面 + 外边界裙边 + 断层崖壁围成封闭三角网。
- **局部重算**:修改/删除钻孔只在其影响半径内重算网格节点并原地刷新顶点,
  不整模重建 (状态栏显示重算节点数与耗时)。
- **任意剖面**:俯视图上手画折线,实时生成二维剖面图(分层填充、断层线、
  走廊内钻孔投影、高程/里程标尺),三维中同步显示切割帘幕。
- **显示**:光照方位/高度/强度、地质体透明度、图例、比例尺、帧率表、
  地质体/界面/岩芯柱/孔迹/标签/断层/帘幕开关、垂向放大。
- **导出**:模型 OBJ(+MTL,按地层分对象分材质)、剖面 PNG、三张表 CSV。
- **工程**:保存/打开 `.geo3d.json`;浏览器 localStorage 自动保存,可恢复上次会话。
- **示例数据**:36 孔,含向东尖灭的页岩层和一条走向 25°、断距 12m 的正断层;
  另有 200 孔压力测试数据生成。

## 数据格式 (CSV, 支持中/英文表头)

- 孔口表:`孔号, X, Y, 标高, 孔深`(英文 `hole, x/easting, y/northing, z/elevation, depth`)
- 测斜表:`孔号, 测深, 顶角, 方位角`(`hole, md, dip, azimuth`;顶角为与铅垂线夹角)
- 分层表:`孔号, 起始深度, 终止深度, 岩性`(`hole, from, to, litho`)

## 参数

网格分辨率、插值方法 (克里金/IDW)、IDW 幂次、影响半径、邻近样本数、
变差函数 (球状/指数/高斯, 块金/基台/变程)、断层 (走向/倾角/位置/断距)、
地层表 (顺序与颜色) 均可在"模型参数"页调整。

## 代码结构

```
src/
  types.ts        数据类型与默认参数
  trajectory.ts   测斜 -> 真实孔迹 (最小曲率法)
  validate.ts     三表一致性校验
  interpolate.ts  IDW / 普通克里金, 网格场, 局部重算
  model.ts        建模引擎: 层厚度法、断层分盘、尖灭夹紧、封闭体、增量更新
  section.ts      折线剖面切割、二维剖面绘制、三维帘幕
  sample.ts       示例数据 (36 孔) 与 200 孔压力测试生成
  io.ts           CSV 导入、工程保存/打开、OBJ 导出
  view3d.ts       Three.js 场景: 岩芯柱合并网格、界面、地质体、光照、比例尺
  ui.ts           面板/表格/剖面绘制/导入导出
scripts/
  smoke.ts        核心算法冒烟测试
  e2e.mjs         浏览器端到端验证 (playwright-core + 系统 Chromium)
```
